## 3. Letterbox Coordinate Mathematics

To resolve previous landmark pin drift under `ContentScale.Fit`:
- Containers compute aspect ratios against the intrinsic image aspect ratio (1.7917).
- If container aspect ratio > image aspect ratio (height-constrained pillarbox):
  `displayedHeight = containerHeight`, `displayedWidth = containerHeight * imageAspect`, `offsetLeft = (containerWidth - displayedWidth) / 2`, `offsetTop = 0`.
- If container aspect ratio <= image aspect ratio (width-constrained letterbox):
  `displayedWidth = containerWidth`, `displayedHeight = containerWidth / imageAspect`, `offsetLeft = 0`, `offsetTop = (containerHeight - displayedHeight) / 2`.
- Pin coordinate:
  `pinX = offsetLeft + (normalizedCoordinateX * displayedWidth)`
  `pinY = offsetTop + (normalizedCoordinateY * displayedHeight)`
- Both the bitmap and the pinpoint markers are transformed by the identical zoom and pan `graphicsLayer`, ensuring zero drift on any screen geometry.

## 4. 3D Model Readiness & Architecture Roadmap

In strict compliance with the user's Zero-Mock Protocol:
- **Current Mode**: High-definition 2D Interactive Landmark Engine with pan/zoom gesture detection, pinpoint markers with coordinate positioning, and structure detail drawers.
- **Why Pseudo-3D was rejected**: Spinning cubes, animated screenshots, or fake CSS/Canvas rotations provide zero clinical utility and violate zero-mock architectural integrity.
- **Requirements for True 3D Release**:
  1. Integration of `io.github.sceneview:sceneview` or Google Filament 3D rendering pipeline.
  2. Polygon models in standardized `.glb` or `.gltf` format with PBR materials and high-precision anatomical UV mapping.
  3. Raycast hit-testing (`hitTest`) mapping pointer coordinates to anatomical mesh IDs for interactive structure selection.
  4. Real-time orbital camera manipulation (azimuth, elevation, distance) with bounded pitch to prevent disorienting camera inversions.
